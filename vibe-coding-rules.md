vibe coding rules

1. do not run commands that deletes, force pushes, rewrite history or reach network without manual approval
2. only touch files that are absolutely required, don't try to refactor the whole project
3. reuse existing dependencies, functions and code whenever you can
4. before writing code analyze why is it required, how to do it, test and verify
5. keep the tasks small, do it for a single feature one by one
